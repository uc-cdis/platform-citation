# Platform-Citation
<img src="docs/img/gen3blue.png" width=250px>
For managing and publishing all language for citing Gen3 platforms

## Testing

This repo uses MkDocs-Material to create the citation platform. 

* [Install MkDocs Material](https://squidfunk.github.io/mkdocs-material/getting-started/) locally (best in a virtual environment).  
* Clone this platform-citation repo locally.  
* Navigate to your cloned repo and activate your VE with MkDocs.  
* Make and save your changes, then [run `mkdocs-serve`](https://www.mkdocs.org/user-guide/cli/#mkdocs-serve). This will give you a local URL where you can view the locally-built and deployed site to preview the effect of your changes. You can continue to make and save changes and they will be immediately applied in the local deployment.  

Alternate approach:  
After activating the virtual env:  

```
poetry install --no-root
poetry run mkdocs serve
```
